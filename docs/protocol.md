# Протокол устройство ↔ сервер

Вход один: `https://178.104.149.56:18443` (в облачном файрволе Hetzner открыт только этот порт).
TLS 1.2 со сертификатом Hbox (`deploy/tls/ca.crt` — его прошиваем в устройство), nginx снимает TLS
и отдаёт `/hbox/` серверу (`server/hbox_server/app.py`).

Устройство — по токену: `Authorization: Bearer <токен>`. Токены и id — `HBOX_DEVICES` в `.env`
сервера (`id:токен,...`). id — это канал в имени файла.

## Файлы с докачкой

Имя: `<канал>_YYYYMMDD_HHMMSS.mp3|m4a`, время начала по UTC.

```
GET /hbox/v1/files/<имя>
→ 200 {"size": <принято байт>, "done": <файл целый>}
```

```
PUT /hbox/v1/files/<имя>?offset=<N>&total=<размер файла>&crc=<CRC-32 всего файла, hex>
Content-Length: <сколько байт в этом запросе>
<байты файла с позиции N>
→ 200 {"size": <принято>, "done": false|true}
→ 409 {"size": <принято>}       N не совпал с тем, что есть на сервере — продолжить с size
→ 422 {"size": 0}               CRC не сошёлся — сервер всё выбросил, слать заново с 0
→ 507                           на сервере нет места — повторить позже
→ 401 / 400                     неизвестный токен / плохое имя или параметры
```

Порядок на устройстве:
1. Файл закрыт (час кончился) — известны размер и CRC-32 (считается при записи).
2. `GET` — сколько уже есть; `done: true` — файл можно помечать отправленным.
3. `PUT` с `offset = size` и всем остатком файла одним запросом (тело потоком через AT+MIPSEND).
4. Обрыв связи — ничего страшного: сервер сохранил всё, что дошло. После переподключения — снова п. 2.

CRC — стандартный CRC-32 (zlib, `esp_rom_crc32_le(0, ...)`). Сервер считает его по мере приёма,
поэтому докачка не требует перечитывать уже принятое.

## Настройки и состояние

```
GET /hbox/v1/config?rec=1&files=12&pending=0&dropped=0&overflows=0&rec_errors=0&cpu=32&csq=27
                    &up_errors=0&sent=11&kbps=54&uptime=95
→ {"record": true, "format": "mp3", "bitrate": 128000, "recheck": 300, "channel": "<id>",
   "time": "2026-11-10T09:00:00Z"}
```

Параметры запроса — состояние устройства для сайта (все числа, любые можно опустить).
`record` сервер считает сам по расписанию (часы работы по дням недели, Asia/Almaty) и выключателю
на сайте; `recheck` — через сколько секунд спросить снова (к ближайшей смене, не больше 300).
`time` — время сервера (UTC): по нему устройство ставит часы при каждом запросе.
Устройства, их токены и настройки — `data/devices.json`, правятся на сайте `/hbox/admin/`.

## Замер скорости

`POST /hbox/speedtest` — тело выбрасывается, ответ — строка со скоростью (hbox-xsg).
