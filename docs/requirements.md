# Требования (заказчик, 2026-11-09)

1. Формат: MP3, моно, 128 кбит/с, 44.1 кГц (заказчик допускал AAC/.m4a и 48 кГц, выбран MP3 моно).
2. Файлы по 1 часу, ровно с начала часа. Имя: ID канала и время начала по UTC, например
   `channel_20261109_100000.mp3`.
3. Объём: ~58 МБ/ч при 128 кбит/с (заказчик закладывает 100–150 МБ/ч, до 1,9 ГБ/сутки).
4. Хранение на устройстве 7 дней (~10–13 ГБ) — microSD.
5. Интернет: нужна только исходящая скорость, минимум 0,5 Мбит/с, рекомендуется от 2 Мбит/с
   (суточная запись догружается за 1,5–2 часа).
6. Запись только в часы работы заведения; включение/выключение записи и расписание — удалённо.
7. Файлы отправляются на наш сервер.
8. Согласие заведений на аудиозапись обеспечивает заказчик.

## Решения

- Платформа: ESP32-S3 на ESP-IDF (SuperMini; PSRAM не обязательна), microSD.
- Модем: ML307R, запасной A7670C (оба проверены в music-monitor, TLS с проверкой нашего CA).
  FS800 DTU и Air780 не берём.
- Отправка: TCP/TLS-сокет модема, свой протокол докачки (позиция, подтверждение, контрольная сумма).
- Сервер — отдельный от music-monitor (Hetzner 178.104.149.56 без места).
